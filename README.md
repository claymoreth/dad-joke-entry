# Dad Joke Showdown — The Steaming Lobster

![Rank](https://make.fun/badge/u-mfnakmal-dad-joke-showdown-1d2ce3e5/claymoreth/dad-joke-entry/rank.svg)

This entry for the Dad Joke Showdown on make.fun delivers exactly one dad joke of 67 characters, built around a pun on "steaming" — the kind of groan-worthy wordplay the competition asks for, in a single short program that writes the joke and nothing else.

Competition: [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the joke to `<output_dir>/entry.txt` with no trailing newline.
